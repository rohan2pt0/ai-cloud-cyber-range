Use it on your phone & iPad

1. Install Tailscale on this laptop and on each phone/iPad, signed in to the same account. Tailscale is the only door in: never open the estate to the Wi-Fi (BIND_HOST=0.0.0.0).
2. Run ./securax phones. It checks what is in the way and shows your private address; ./securax phones --apply publishes it to your own devices only.
3. On the phone/iPad open https://<laptop>.<tailnet>.ts.net, then Add to Home Screen (iPhone/iPad: Share → Add to Home Screen; Android: Chrome menu → Install app).
4. Keep devices in sync: run ./securax go on the laptop (it opens a one-click sync link) and ./securax sync-link for the phone link. To stay in sync with the laptop off, turn on Ops → Connections → OneDrive sync in the app on each device, with the same passphrase (doc 72). sovereign Your data stays on your box.

Make answers fast (optional, free)

Run ./securax setup and paste a free Google AI Studio key (aistudio.google.com/apikey). Answers then come from fast cloud Gemini; without it, the private local model is used (slower on a laptop). Sensitive data always stays local either way.

AI provider plugins

Add any provider — OpenAI, Anthropic, DeepSeek, Mistral, Grok, Perplexity, Azure AI Foundry, AWS Bedrock, OpenRouter — with one command; its model then appears in Chat, still routed through the security gateway:
./securax providers add

Handy commands

Where to run these: in a terminal, inside your ai-cloud-cyber-range folder. On Windows PowerShell type .\securax.cmd up (or .\securax.cmd doctor, …); in Ubuntu/WSL, Mac or Linux type ./securax up.
./securax up  ·  ./securax status  ·  ./securax doctor  ·  ./securax setup  ·  ./securax down
On Windows, START-HERE-Windows.bat / STOP-Windows.bat are for double-clicking in File Explorer — they won't run if you type them inside WSL/bash. In WSL, use ./securax up / ./securax down instead.
