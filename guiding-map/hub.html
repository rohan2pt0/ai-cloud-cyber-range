      Explore everything SecuRAX can do

      Open takes you there when it runs here; otherwise press the command to copy it, then paste it in a terminal inside your ai-cloud-cyber-range folder.

      Use it on your phone and iPad
      1. Install Tailscale on this laptop and on each phone or iPad, signed in to the same account. Never open the estate to the Wi-Fi.
      2. Run ./securax phones, then ./securax phones --apply to publish it to your own devices only.
      3. On the phone, open https://<laptop>.<tailnet>.ts.net and choose Add to Home Screen.
      4. To stay in sync with the laptop off, turn on Ops → Connections → OneDrive sync on each device, with the same passphrase.
      Faster answers and AI providers

      Run ./securax setup and paste a free Google AI Studio key for fast answers; without it the private local model answers. Sensitive data always stays local.

      Add OpenAI, Anthropic, DeepSeek, Mistral, Grok, Perplexity, Azure AI Foundry, AWS Bedrock or OpenRouter with ./securax providers add; every call still goes through the security gateway.
