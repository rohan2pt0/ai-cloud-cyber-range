Optional add-ons (each needs a little setup before it's useful)

Use it on your phone & iPad

1. Let other devices reach it. In local/compose/.env set BIND_HOST=0.0.0.0 (same Wi-Fi) — or your Tailscale IP for secure access anywhere — then restart: ./securax up.
2. On the phone/iPad (same network), open http://<this-laptop-IP>:8088. Find the laptop IP with hostname -I (Linux/WSL) or ipconfig (Windows).
3. Install it as an app: in the browser menu choose “Add to Home screen” (iPhone/iPad: Share → Add to Home Screen).
4. Keep all devices in sync: open the Guiding Map → Ops → Cross-device sync, paste the same sync token on every device (./securax setup can generate it). sovereign Your data stays on your box.
Tip: full offline “install” needs a secure URL — plain Wi-Fi works as a web page; Tailscale gives the full installable experience anywhere.

Make answers fast (optional, free)

Run ./securax setup and paste a free Google AI Studio key (aistudio.google.com/apikey). Answers then come from fast cloud Gemini; without it, the private local model is used (slower on a laptop). Sensitive data always stays local either way.

AI provider plugins

Add any provider — OpenAI, Anthropic, DeepSeek, Mistral, Grok, Perplexity, Azure AI Foundry, AWS Bedrock, OpenRouter — with one command; its model then appears in Chat, still routed through the security gateway:
./securax providers add

Handy commands

Where to run these: in a terminal — on Windows open Ubuntu/WSL (or PowerShell), on Mac/Linux open Terminal — then cd into your ai-cloud-cyber-range folder.
./securax up  ·  ./securax status  ·  ./securax doctor  ·  ./securax setup  ·  ./securax down
On Windows, START-HERE-Windows.bat / STOP-Windows.bat are for double-clicking in File Explorer — they won't run if you type them inside WSL/bash. In WSL, use ./securax up / ./securax down instead.
