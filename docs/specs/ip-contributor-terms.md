# Spec: ip-contributor-terms

Queue item `ip-contributor-terms` in `governance/queue.json` · due 2026-11-26 · added 2026-11-08.

**The ask, as the queue holds it:** Every outside contribution licensed to the owner, so the code stays clean to license and sell

## Outcome for the person

Every outside contribution can be licensed and sold cleanly.

## Data

A sign-off on each outside commit; one line in CONTRIBUTING.

## Screen (one action)

On a pull request: one check, signed off or not.

## Test that proves it

A workflow test that the check exists and exempts only the owner and the bots.

## Evolution rail (amoeba to enterprise)

- **Amoeba, today:** A sign-off check.
- **Enterprise, when conditions call for it:** A contributor agreement once a company holds the rights.
