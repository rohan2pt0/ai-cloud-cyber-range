# Spec: industry-pages

Queue item `industry-pages` in `governance/queue.json` · due 2026-11-12 · added 2026-10-22.

**The ask, as the queue holds it:** Industry pages for SEBI entities and DPDP-bound firms (healthcare, SaaS, professional services), each with a sample

## Outcome for the person

A buyer in a regulated industry sees, in a minute, what readiness looks like for a firm like theirs.

## Data

One page per industry with a sample assessment built from public requirements, paraphrased.

## Screen (one action)

Each page: one button, `See the sample`.

## Test that proves it

The site audit (both themes, phone width) and a check that every claim on a page maps to a test or a sample file.

## Evolution rail (amoeba to enterprise)

- **Amoeba, today:** Static pages.
- **Enterprise, when conditions call for it:** Pages generated from the readiness maps per sector and country.
