Maintainers are the default code owners (see [`.github/CODEOWNERS`](.github/CODEOWNERS)) and are
responsible for reviews, releases and security response ([`SECURITY.md`](SECURITY.md)).

Interested in becoming a maintainer? Contribute consistently, help triage, and open a discussion —
see [`GOVERNANCE.md`](GOVERNANCE.md).
