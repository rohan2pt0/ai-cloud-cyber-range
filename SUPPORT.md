# Getting Support

Thanks for using SecuRAX. Here is the fastest route for each kind of question.

| I want to… | Go to |
|---|---|
| **Start using it** | [`GETTING-STARTED.md`](GETTING-STARTED.md) — one step |
| **Understand a capability** | [`docs/securax/`](docs/securax/) (indexed in `00-OVERVIEW.md`) |
| **Report a bug** | Open a [Bug report](https://github.com/rohan2pt0/ai-cloud-cyber-range/issues/new?template=bug_report.yml) |
| **Request a feature** | Open a [Feature request](https://github.com/rohan2pt0/ai-cloud-cyber-range/issues/new?template=feature_request.yml) |
| **Ask a question / discuss an idea** | Open a [Discussion](https://github.com/rohan2pt0/ai-cloud-cyber-range/discussions) (or an issue if Discussions are off) |
| **Report a security vulnerability** | **Do not open a public issue** — see [`SECURITY.md`](SECURITY.md) |
| **Contribute** | [`CONTRIBUTING.md`](CONTRIBUTING.md) |

Before filing: please search existing issues/discussions, and include your SecuRAX version
(`cat VERSION`, or the gateway `/version` endpoint), OS, and reproduction steps.

This is a community project maintained on a best-effort basis — there is no paid support SLA.
